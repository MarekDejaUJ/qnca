Preface

Quantile Necessary Condition Analysis (QNCA) asks how much of a condition the successful cases hold when a stated share of the successful cases may sit below the reported requirement. For each target level of an outcome, QNCA takes the cases that reach the target and reports a low quantile of the condition among the cases. The tolerance pi in (0, 1] fixes the share 1 - pi of successful cases that may fall below the requirement. At pi = 1 the requirement is the lowest condition value among the successful cases, which is the CE-FDH ceiling of Necessary Condition Analysis (NCA) (Dul 2016). At pi = 0.95 the requirement admits five percent of the successful cases below the reported level (Deja 2026b).

The guide explains the method and the software through one question per chapter. Each chapter defines the quantities the chapter uses and reads without the other chapters. Each chapter computes the example of the chapter in R and repeats the central call in Python and Julia, and every number in the text is the output of the code shown beside the number. The books of Jan Dul describe the procedure of NCA from theory to reporting (Dul 2020, 2025); the guide cites the books for the procedure of NCA and builds the route of QNCA from the tolerance.

Software

The R and Python packages are named qnca, and the Julia package is named QuantileNecessity. The three implementations give the same effect sizes and the same bottlenecks on the same data.

install.packages("qnca")
python -m pip install qnca
using Pkg
Pkg.add("QuantileNecessity")

The development versions install from the repository https://github.com/MarekDejaUJ/qnca, which also holds the datasets of the guide in the data folder. The examples read the datasets from the repository over the internet, so every example runs as printed.

Citation

The article that introduces the method is Deja (2026b). The software of release 0.4.0 is archived at Zenodo (Deja 2026a).
