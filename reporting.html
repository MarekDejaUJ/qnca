13 Reporting QNCA and QNCA in cIPMA

A QNCA report states, for each outcome target y, the requirement on the condition X among the cases that attain Y >= y at a declared tolerance pi in (0, 1], where 1 - pi is the share of the successful cases that may fall below the requirement. At pi = 1 the requirement is the CE-FDH ceiling of Necessary Condition Analysis (NCA) (Dul 2016). A report fixes the tolerance grid and the scope before the analysis, gives the frontier, the bottlenecks and the effect sizes together, and keeps outlier-fragility and spuriousness apart as two failure modes with two diagnostics (Deja 2026b).

13.1 The elements of a report

Table 13.1 lists the elements in the order of reading.

Table 13.1: Elements of a QNCA report and the reason for each, after Deja (2026b).
Element Content Reason
Tolerance grid A small grid fixed in advance, with the strict anchor 1.00, for example 1.00, 0.95 and 0.90 Lowering pi raises the bottleneck and d_pi by construction and changes the estimand; pi is chosen before any p-value is seen
Scope The rectangle [x_min, x_max] x [y_min, y_max] and its source, data range or external anchors The effect size divides an area by the scope area
Effect sizes and p-values d_pi and the permutation p-value p_pi at every tolerance of the grid Each tolerance has its own statistic and its own p-value
Bottlenecks The requirement at the important targets, with the conditioning-set size k and the selected rank The same percentage maps to different ranks as k falls
Marks Bottlenecks inherited from a lower target and bottlenecks limited by tail size An inherited bottleneck repeats a lower requirement, and a small k returns the minimum
Tolerance path The pointwise movement of the bottlenecks and the gap d_pi - d_1 The path diagnoses outlier-fragility at particular targets
Reference band Delta = d_obs - U and p_null at every tolerance, labelled as a proposed diagnostic The band addresses spuriousness from dependence and skew
Limitations Variance estimation, preliminary calibration, the upper-left configuration The claims of the report stay within the evidence

Tolerance values well below one answer different questions: pi = 0.50 reports the median condition level among the successful cases and needs a substantive loss function or exception policy (Deja 2026b). The strict value 1.00 suits a decision in which a single observed success below a requirement rejects the requirement, and a small positive exception tolerance suits a decision that should rest on more than a few exceptional successes.

13.2 A report on the synthetic data

The synthetic dataset of 200 cases of the qnca repository has a condition and an outcome on a scale from 0 to 100. The report fixes the grid 1.00, 0.95 and 0.90, the scope [0, 100] x [0, 100] from the anchors of the measurement scale, 101 outcome levels and one matrix of 499 permutations shared by the three tolerances.

library(qnca)
d <- read.csv("https://raw.githubusercontent.com/MarekDejaUJ/qnca/main/data/qnca_dataset_n200.csv")
grid_pi <- c(1, 0.95, 0.90)
scope <- c(0, 100, 0, 100)
set.seed(1)
perm <- t(replicate(499, sample.int(nrow(d))))
fits <- lapply(grid_pi, function(p)
  qnca(d$X, d$Y, pi = p, n_grid = 101, scope = scope, permutations = perm))
data.frame(pi = grid_pi, d_pi = sapply(fits, `[[`, "d_pi"), p_pi = sapply(fits, `[[`, "p_pi"))
#>     pi      d_pi  p_pi
#> 1 1.00 0.4936575 0.002
#> 2 0.95 0.5422595 0.002
#> 3 0.90 0.5903942 0.002

The effect sizes are 0.494, 0.542 and 0.590 at pi = 1.00, 0.95 and 0.90, each with the p-value 0.002, the smallest value that 499 permutations allow. The bottleneck table reports the targets 20, 50 and 80 with the conditioning-set size, the selected rank and the two marks. A bottleneck counts as limited by tail size when pi < 1 and the selected rank is 1, because the tolerance then returns the strict minimum.

targets <- c(20, 50, 80)
report <- do.call(rbind, lapply(grid_pi, function(p) {
  r <- qnca_resolution(d$X, d$Y, pi = p, n_grid = 101, scope = scope)
  r <- r[match(targets, r$y), ]
  data.frame(target = targets, pi = p, k = r$k, rank = r$rank, bottleneck = r$fitted,
             inherited = r$inherited, tail_limited = p < 1 & r$rank == 1)
}))
report[order(report$target, -report$pi), ]
#>   target   pi  k rank bottleneck inherited tail_limited
#> 1     20 1.00 75    1   9.044073     FALSE        FALSE
#> 4     20 0.95 75    4  15.761165     FALSE        FALSE
#> 7     20 0.90 75    8  28.390844     FALSE        FALSE
#> 2     50 1.00 27    1  45.854808     FALSE        FALSE
#> 5     50 0.95 27    2  53.272228     FALSE        FALSE
#> 8     50 0.90 27    3  59.368200      TRUE        FALSE
#> 3     80 1.00  4    1  89.703340     FALSE        FALSE
#> 6     80 0.95  4    1  89.703340     FALSE         TRUE

At the target 50, 27 cases attain the target, and the bottleneck rises from 45.85 at the strict member to 53.27 at pi = 0.95 and 59.37 at pi = 0.90, with the selected ranks 1, 2 and 3; the bottleneck at pi = 0.90 is inherited from a lower target. At the target 80, four cases attain the target, every tolerance selects rank 1 and returns 89.70, and the two tolerant bottlenecks carry the tail-size mark. The pointwise path at the target 20, from 9.04 to 15.76 and 28.39, shows the largest movement of the three targets.

band <- spuriousness_band(d$X, d$Y, pi_grid = grid_pi, n_grid = 101, M = 199,
                          scope = scope, seed = 1)
band$band[, c("pi", "d_obs", "upper", "excess", "p_null")]
#>     pi     d_obs     upper     excess p_null
#> 1 1.00 0.4936575 0.3921033 0.10155424  0.005
#> 2 0.95 0.5422595 0.4663901 0.07586941  0.005
#> 3 0.90 0.5903942 0.5271056 0.06328861  0.005

The reference band with 199 null replicates gives a positive excess at every tolerance, 0.102, 0.076 and 0.063, so the empty zone exceeds the Gaussian-copula benchmark that keeps the marginals and the rank dependence of the two variables. The band is a proposed diagnostic with operating characteristics still to be established, and the report states the status of the band beside the numbers. The limitations of the report follow from the method: variance estimation and confidence procedures for a given sample remain open, the calibration screens of the permutation test are preliminary, and the method covers the upper-left configuration, where a high outcome requires a high condition (Deja 2026b).

13.3 QNCA in the cIPMA package

The combined importance-performance map analysis (cIPMA) of Hauff, Richter, Sarstedt and Ringle starts from a partial least squares model and a target construct (Hauff et al. 2024). The map places each predictor by importance, the total effect on the target, against performance, the mean of the latent scores rescaled to 0–100, and the analysis adds the necessity of each predictor. The cIPMA package 0.2.0 computes the necessity part with qnca. Necessity is decided at the strict limit pi = 1, where the QNCA frontier equals the CE-FDH ceiling: on the data-range scope of each pair, a predictor is necessary when the CE-FDH effect size reaches 0.10 and the permutation p-value stays below 0.05, the rule of Hauff et al. (2024). The bottleneck and the share of cases below the bottleneck follow the chosen tolerance, and the tolerance path repeats the effect size and the bottleneck from pi = 1.00 to pi = 0.90 in steps of 0.01.

The mobi data of the seminr package (Ray et al. 2026) hold the answers of 250 customers of a mobile phone provider on the items of the European customer satisfaction index model, on scales from 1 to 10. The target is loyalty at level 80 of 100, the bottleneck uses the tolerance pi = 0.95, the bootstrap of the model uses 100 resamples and the permutation test 199 permutations.

library(seminr)
library(cIPMA)
mm <- constructs(
  composite("Image", multi_items("IMAG", 1:5)),
  composite("Expectation", multi_items("CUEX", 1:3)),
  composite("Quality", multi_items("PERQ", 1:7)),
  composite("Value", multi_items("PERV", 1:2)),
  composite("Satisfaction", multi_items("CUSA", 1:3)),
  composite("Complaints", single_item("CUSCO")),
  composite("Loyalty", multi_items("CUSL", 1:3))
)
sm <- relationships(
  paths(from = "Image", to = c("Expectation", "Satisfaction", "Loyalty")),
  paths(from = "Expectation", to = c("Quality", "Value", "Satisfaction")),
  paths(from = "Quality", to = c("Value", "Satisfaction")),
  paths(from = "Value", to = "Satisfaction"),
  paths(from = "Satisfaction", to = c("Complaints", "Loyalty")),
  paths(from = "Complaints", to = "Loyalty")
)
pls <- suppressMessages(estimate_pls(mobi, mm, sm))
boot <- suppressMessages(bootstrap_model(pls, nboot = 100, cores = 1, seed = 123))
scales <- setNames(rep(list(c(1, 10)), ncol(mobi)), names(mobi))
res <- cipma(boot, "Loyalty", mobi, scales, target_level = 80, pi = 0.95,
             B = 199, seed = 1, pls_model = pls)
summary(res)

Four predictors meet the rule at the strict limit: image, expectation, quality and satisfaction, with CE-FDH effect sizes from 0.122 to 0.151 and p-values from 0.005 to 0.020. Value and complaints have the effect size 0.016 and miss the rule. At pi = 0.95, loyalty of at least 80 requires 67.209 on satisfaction, and 29.2 percent of the customers fall below the required level; the required level of image is 63.566, with 21.6 percent of the customers under the required level. The effect sizes at pi = 0.95 lie between 0.316 and 0.421 for all six predictors, value and complaints included, because an effect size at pi < 1 is relative to the tolerance and the NCA landmark of 0.10 applies to the CE-FDH effect size. The package therefore keeps the decision on necessity at the strict limit.

13.4 The same call in Python and Julia

The Python package qnca and the Julia package QuantileNecessity reproduce the effect sizes and the bottleneck table of the synthetic report; the cIPMA package runs in R.

from urllib.request import urlopen
import numpy as np
from qnca import qnca, qnca_resolution

url = "https://raw.githubusercontent.com/MarekDejaUJ/qnca/main/data/qnca_dataset_n200.csv"
X, Y = np.loadtxt(urlopen(url), delimiter=",", skiprows=1, unpack=True)
scope = (0, 100, 0, 100)
for pi in (1.0, 0.95, 0.90):
    fit = qnca(X, Y, pi=pi, n_grid=101, B=None, scope=scope)
    res = qnca_resolution(X, Y, pi=pi, n_grid=101, scope=scope)
    rows = [int(np.flatnonzero(res.y == t)[0]) for t in (20.0, 50.0, 80.0)]
    print(f"{pi:.2f}", round(fit.d_pi, 4), res.k[rows], res.rank[rows], np.round(res.fitted[rows], 2))
#> 1.00 0.4937 [75 27  4] [1 1 1] [ 9.04 45.85 89.7 ]
#> 0.95 0.5423 [75 27  4] [4 2 1] [15.76 53.27 89.7 ]
#> 0.90 0.5904 [75 27  4] [8 3 1] [28.39 59.37 89.7 ]
using QuantileNecessity, Downloads, DelimitedFiles

url = "https://raw.githubusercontent.com/MarekDejaUJ/qnca/main/data/qnca_dataset_n200.csv"
data = readdlm(Downloads.download(url), ',', Float64; skipstart = 1)
X, Y = data[:, 1], data[:, 2]
scope = (0, 100, 0, 100)
for pi in (1.0, 0.95, 0.90)
    fit = qnca(X, Y; pi = pi, n_grid = 101, B = 0, scope = scope)
    res = qnca_resolution(X, Y; pi = pi, n_grid = 101, scope = scope)
    rows = [findfirst(==(t), res.y) for t in (20.0, 50.0, 80.0)]
    println(pi, " ", round(fit.d_pi; digits = 4), " ", res.k[rows], " ", res.rank[rows], " ",
            round.(res.fitted[rows]; digits = 2))
end
#> 1.0 0.4937 [75, 27, 4] [1, 1, 1] [9.04, 45.85, 89.7]
#> 0.95 0.5423 [75, 27, 4] [4, 2, 1] [15.76, 53.27, 89.7]
#> 0.9 0.5904 [75, 27, 4] [8, 3, 1] [28.39, 59.37, 89.7]

A report that fixes the grid in advance, keeps the strict anchor and shows the rank behind each important bottleneck lets a reader see which targets rest on a few efficient cases. The band, read as a proposed diagnostic, adds whether the empty zone exceeds the dependence of the two variables.
