14 The three implementations

The R package qnca, the Python package qnca and the Julia package QuantileNecessity implement one estimator. At each outcome target y on a grid, each implementation selects a low type-1 quantile of the condition among the cases with Y >= y at the tolerance pi. The monotone envelope makes the frontier non-decreasing, the frontier takes the upper bound of the condition in an unobserved top band of a fixed scope, and the trapezoid rule integrates the empty zone into the effect size d_pi. The implementations in R (R Core Team 2025), in Python with NumPy (Harris et al. 2020) and in Julia (Bezanson et al. 2017) carry out the same steps, so the three give the same effect sizes to floating point and the same bottlenecks on the same data (Deja 2026b).

The type-1 quantile is the inverse empirical distribution function, and the type-1 quantile at probability zero is the sample minimum. The tolerance pi = 1 therefore reproduces the CE-FDH running minimum of Necessary Condition Analysis (NCA) before numerical integration, and every fitted value of the frontier at an attained target is an observed condition value. An interpolating quantile would replace the observed order statistics with interpolated values and weaken the strict-limit property (Hyndman and Fan 1996).

14.2 Functions across the three languages

Table 14.1 maps the functions of the three packages. The R and Python functions take named arguments, and the Julia functions take keyword arguments after a semicolon. The monotone fit is the string "envelope" or "isotonic" in R and Python and the symbol :envelope or :isotonic in Julia. Permutation matrices and subsample matrices hold one-based indices in all three languages. A fit returns a list with a data frame in R, a data class in Python and a named tuple in Julia.

14.3 The selected rank from the exact decimal of the tolerance

At a target with k attaining cases, the frontier selects the order statistic of rank h = max(1, ceiling(k * (1 - pi))). In binary floating point, 1 - 0.95 is slightly larger than 0.05, so 100 * (1 - 0.95) lies slightly above 5 and a direct ceiling returns 6.

library(qnca)
sprintf("%.20f", 1 - 0.95)
#> [1] "0.05000000000000004441"
c(direct = ceiling(100 * (1 - 0.95)), qnca_rank = qnca_rank(100, 0.95))
#>    direct qnca_rank 
#>         6         5
c(direct = ceiling(1000 * (1 - 0.99)), qnca_rank = qnca_rank(1000, 0.99))
#>    direct qnca_rank 
#>        11        10

The three implementations read the tolerance from the shortest decimal that represents the floating-point value and form the rank in exact arithmetic. R splits the integer arithmetic below 2^53, Python uses fractions.Fraction of the decimal text, and Julia parses a rational number from the decimal text. The tolerance 0.95 with 100 attaining cases therefore selects rank 5 in all three languages, and 0.99 with 1000 attaining cases selects rank 10.

14.5 A shared permutation matrix

A permutation p-value depends on the permutations, and the three languages draw different permutations from the generator of each language. The argument permutations of qnca() accepts a matrix with B rows, each row a one-based permutation of the n cases, and three implementations that score the same matrix return the same p-value. The multiplicative congruential generator with multiplier 16807 and modulus 2^31 - 1 (Park and Miller 1988) runs in exact integer arithmetic in all three languages, so each language can build the same matrix by ordering consecutive blocks of n values.

d <- read.csv("https://raw.githubusercontent.com/MarekDejaUJ/qnca/main/data/qnca_dataset_n100.csv")
lcg <- function(count, seed) {
  x <- numeric(count)
  s <- seed
  for (k in seq_len(count)) {
    s <- (16807 * s) %% 2147483647
    x[k] <- s
  }
  x
}
B <- 199
n <- nrow(d)
perm <- t(apply(matrix(lcg(B * n, 1), nrow = B, byrow = TRUE), 1, order))
perm[1, 1:10]
#>  [1]  1 18 83 14  7 34 78 15 60 20
for (p in c(1, 0.95, 0.90)) {
  fit <- qnca(d$X, d$Y, pi = p, n_grid = 50, scope = c(0, 100, 0, 100), permutations = perm)
  cat(sprintf("%.2f %.12f %.12f\n", p, fit$d_pi, fit$p_pi))
}
#> 1.00 0.496231091316 0.005000000000
#> 0.95 0.521827525269 0.005000000000
#> 0.90 0.546650677260 0.005000000000

On the dataset of 100 cases, R gives the effect sizes 0.496231091316, 0.521827525269 and 0.546650677260 at pi = 1.00, 0.95 and 0.90, the values of the stored cross-language check, and the p-value 0.005 at each tolerance, the smallest value that 199 permutations allow.

The Julia function qnca() draws all B permutations from one seeded stream before the permutations are scored, and the scoring runs in a threaded loop. The p-value for a given seed is therefore the same for every number of threads with which Julia starts. The reference band of the Julia package draws the array of normal variates from one seeded stream in the same way before the threaded loop over the null replicates. The R and Python implementations score the permutations in sequence.

14.6 The same computation in Python and Julia

The Python and Julia chunks build the same permutation matrix, print the same first row and give the same effect sizes and p-values to 12 decimals, together with the direct and the exact rank of pi = 0.95 with 100 attaining cases.

from urllib.request import urlopen
import math
import numpy as np
from qnca import qnca, qnca_rank

url = "https://raw.githubusercontent.com/MarekDejaUJ/qnca/main/data/qnca_dataset_n100.csv"
X, Y = np.loadtxt(urlopen(url), delimiter=",", skiprows=1, unpack=True)

def lcg(count, seed):
    x = np.empty(count)
    s = seed
    for k in range(count):
        s = (16807 * s) % 2147483647
        x[k] = s
    return x

B, n = 199, X.size
perm = np.argsort(lcg(B * n, 1).reshape(B, n), axis=1, kind="stable") + 1
print(perm[0, :10])
for pi in (1.0, 0.95, 0.90):
    fit = qnca(X, Y, pi=pi, n_grid=50, scope=(0, 100, 0, 100), permutations=perm)
    print(f"{pi:.2f} {fit.d_pi:.12f} {fit.p_pi:.12f}")
print(math.ceil(100 * (1 - 0.95)), qnca_rank(100, 0.95))
#> [ 1 18 83 14  7 34 78 15 60 20]
#> 1.00 0.496231091316 0.005000000000
#> 0.95 0.521827525269 0.005000000000
#> 0.90 0.546650677260 0.005000000000
#> 6 5
using QuantileNecessity, Downloads, DelimitedFiles, Printf

url = "https://raw.githubusercontent.com/MarekDejaUJ/qnca/main/data/qnca_dataset_n100.csv"
data = readdlm(Downloads.download(url), ',', Float64; skipstart = 1)
X, Y = data[:, 1], data[:, 2]

function lcg(count, seed)
    x = zeros(count)
    s = seed
    for k in 1:count
        s = mod(16807 * s, 2147483647)
        x[k] = s
    end
    return x
end

B, n = 199, length(X)
u = permutedims(reshape(lcg(B * n, 1), n, B))
perm = reduce(vcat, [sortperm(u[b, :])' for b in 1:B])
println(perm[1, 1:10])
for pi in (1.0, 0.95, 0.90)
    fit = qnca(X, Y; pi = pi, n_grid = 50, scope = (0, 100, 0, 100), permutations = perm)
    @printf("%.2f %.12f %.12f\n", pi, fit.d_pi, fit.p_pi)
end
println(ceil(Int, 100 * (1 - 0.95)), " ", qnca_rank(100, 0.95))
#> [1, 18, 83, 14, 7, 34, 78, 15, 60, 20]
#> 1.00 0.496231091316 0.005000000000
#> 0.95 0.521827525269 0.005000000000
#> 0.90 0.546650677260 0.005000000000
#> 6 5

Equal effect sizes need the same data, scope, grid and tolerance, and equal p-values need in addition the same permutation matrix; with both, an analysis moves between R, Python and Julia with every reported number unchanged.
