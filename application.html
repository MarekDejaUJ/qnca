12 A technology acceptance reanalysis

The combined importance-performance map analysis (cIPMA) of Hauff, Richter, Sarstedt and Ringle reports the CE-FDH effect sizes of Necessary Condition Analysis (NCA) for the antecedents of technology use in a survey of adopters of e-book readers (Hauff et al. 2024). QNCA adds three questions to the published CE-FDH analysis (Deja 2026b). How does each boundary move over a small tolerance grid fixed in advance? Does the strict bottleneck depend on a few efficient cases? Does the empty zone exceed a benchmark that keeps the observed marginals and rank dependence? For an applied decision, the bottleneck is a feasibility floor.

12.1 Latent scores of the published model

The survey of French adopters of e-book readers of Richter et al. (2023) is the file “Extended TAM.csv” on Mendeley Data (Schubring and Richter 2023). The model has five composites with three items each on scales from 1 to 5: perceived usefulness (PU), compatibility (CO), ease of use (EOU), emotional value (EMV) and adoption intention (AD). Technology use (USE) is a single item on a scale from 1 to 7. PU, CO, EOU and EMV lead to AD, and all five constructs lead to USE. The package seminr estimates the model by partial least squares (Ray et al. 2026). Each latent score is the weighted mean of the items of the construct with the normalised unstandardised weights of the model. The function get_rescaled_scores() of the cIPMA package rescales each score from the item scale to the range from 0 to 100, as in the cIPMA workflow (Hauff et al. 2024).

library(qnca)
library(seminr)

                fileEncoding = "UTF-8-BOM", check.names = FALSE)
nrow(tam)

  composite("CO", multi_items("CO_0", 1:3)),
  composite("EOU", multi_items("EOU_0", 1:3)),
  composite("EMV", multi_items("EMV_0", 1:3)),
  composite("AD", multi_items("AD_0", 1:3)),
  composite("USE", single_item("USE_01"))
)
sm <- relationships(
  paths(from = c("CO", "PU", "EOU", "EMV"), to = "AD"),
  paths(from = c("AD", "CO", "PU", "EOU", "EMV"), to = "USE")

rescaled_scores <- function(model, data, scales) {
  w <- as.data.frame(as.table(model$outer_weights))
  names(w) <- c("item", "construct", "weight")
  w <- w[w$weight != 0, ]
  w$weight <- w$weight / model$sdData[as.character(w$item)]
  w$weight <- w$weight / ave(w$weight, w$construct, FUN = sum)
  model$measurement_model <- model$mmMatrix
  model$construct_scores <- sapply(split(w, w$construct, drop = TRUE), function(s)
    as.matrix(data[, as.character(s$item)]) %*% s$weight)
  out <- as.data.frame(cIPMA::get_rescaled_scores(model, scales))
  out[] <- lapply(out, function(v) pmin(100, pmax(0, v)))
  out
}
scales <- setNames(rep(list(c(1, 5)), ncol(tam)), names(tam))

The function nca_ce_fdh_d() computes the CE-FDH effect size exactly on the empirical scope of each pair, the scope of the published illustration. The five effect sizes reproduce the published values of AD, EMV, EOU, PU and CO to printed rounding, with differences of at most 0.005 in absolute value.

The latent scores depend on the structural model, because the inner weights of partial least squares shape the outer weights. A chain specification with the paths EOU to PU and AD, PU, EMV and CO to AD, and AD to USE, the specification of the replication archive of Deja (2026b), gives a second set of scores from the same items.

sm_chain <- relationships(
  paths(from = "EOU", to = c("PU", "AD")),
  paths(from = c("PU", "EMV", "CO"), to = "AD"),
  paths(from = "AD", to = "USE")
)
scores_chain <- rescaled_scores(suppressMessages(estimate_pls(tam, mm, sm_chain)), tam, scales)
effects <- function(s) c(
  min_EOU = min(s$EOU),
  EOU_1.00 = nca_ce_fdh_d(s$EOU, s$USE),
  EOU_0.95 = qnca(s$EOU, s$USE, pi = 0.95, n_grid = 400, B = 0)$d_pi,
  PU_1.00 = nca_ce_fdh_d(s$PU, s$USE),
  PU_0.95 = qnca(s$PU, s$USE, pi = 0.95, n_grid = 400, B = 0)$d_pi)
round(rbind(published_model = effects(scores), chain_model = effects(scores_chain)), 3)
#>                 min_EOU EOU_1.00 EOU_0.95 PU_1.00 PU_0.95
#> published_model  16.871    0.235    0.432   0.243   0.439
#> chain_model      17.721    0.199    0.424   0.248   0.445

The chain specification raises the lowest EOU score from 16.871 to 17.721 and lowers the strict EOU effect from 0.235 to 0.199, whereas the EOU effect at pi = 0.95 moves from 0.432 to 0.424. A change of 0.036 in the strict effect between two nearly identical sets of scores is the kind of sensitivity that the tolerance path measures within one set of scores (Deja 2026b). The tolerance path, the deletion screen and the band follow the specification and the settings of the reanalysis in Deja (2026b). The settings are the scores of the chain specification, the empirical scope of each pair, 400 outcome levels, one matrix of 1999 permutations per pair shared by the three tolerances, and 999 null replicates in the band.

12.2 The tolerance path and the permutation test

The tolerance grid 1.00, 0.95 and 0.90 is fixed before the analysis and keeps the strict anchor.

s <- scores_chain
n <- nrow(s)
pi_grid <- c(1, 0.95, 0.90)
fits <- lapply(seq_along(pairs), function(idx) {
  X <- s[[pairs[idx]]]; Y <- s$USE
  scope <- c(min(X), max(X), min(Y), max(Y))
  set.seed(20260930L + idx)
  perms <- t(replicate(1999, sample.int(n, n, replace = FALSE)))
  lapply(pi_grid, function(pi)
    qnca(X, Y, pi = pi, n_grid = 400L, B = NA, scope = scope, permutations = perms))
})
get <- function(field, j) sapply(fits, function(f) f[[j]][[field]])
path <- data.frame(pair = paste(pairs, "-> USE"),
                   d_1.00 = get("d_pi", 1), d_0.95 = get("d_pi", 2), d_0.90 = get("d_pi", 3),
                   p_1.00 = get("p_pi", 1), p_0.95 = get("p_pi", 2), p_0.90 = get("p_pi", 3))
path$gap_0.95 <- path$d_0.95 - path$d_1.00
path$gap_0.90 <- path$d_0.90 - path$d_1.00
path$relative_gap_0.95 <- path$gap_0.95 / path$d_1.00
print(path, digits = 3, row.names = FALSE)

The strict effect sizes 0.294, 0.331 and 0.210 reproduce the published CE-FDH values of AD, EMV and CO to printed rounding, and the chain-specification scores give 0.199 for EOU and 0.248 for PU against the published 0.24 and 0.24. At pi = 0.95, all five pairs give p-values below 0.05, from 0.0005 to 0.0495. The strict p-values run from 0.0005 to 0.0555. EOU misses 0.05 at pi = 1.00 and falls below 0.05 at both tolerances fixed in advance. The effect sizes rise from pi = 1.00 to 0.95 and 0.90 in every pair as larger exception tolerances move the bottleneck away from the most efficient respondents, and the three effect sizes form a sensitivity reading (Deja 2026b).

12.3 Dependence on a few efficient respondents

The effect-size gap d_0.95 - d_1.00 measures how far a five-percent exception tolerance moves the empty zone. The gap is 0.247 for AD, 0.225 for EOU, 0.197 for PU, 0.194 for CO and 0.169 for EMV, and the gaps at pi = 0.90 run from 0.237 to 0.330. A five-percent exception tolerance therefore raises the empty zone by about four fifths or more for AD, EOU, PU and CO and by about half for EMV. Each strict boundary rests heavily on the few successful respondents with the lowest condition scores, and the strict member is the most outlier-fragile frontier of the grid. The application keeps the empirical scope of each pair, so the gap magnitudes compare within the table and transfer to other scopes only with a recalibration.

Tail size limits the same reading. Nine respondents attain the highest level of USE, and with fewer than 20 successful cases the rank max(1, ceiling(k * (1 - pi))) at pi = 0.95 selects the minimum. A report marks the top bottlenecks as limited by tail size and the bottlenecks of EMV and CO at the top as inherited.

The deletion screen of qnca_outliers() gives the case-level view in the manner of the NCA outlier screen (Dul 2026). The largest rise of the strict effect from the deletion of one respondent is 0.05 to 0.08 across the five pairs, between 22 and 32 percent of the strict effect. The largest rise from the deletion of two respondents reaches 0.12, 60 percent of the strict EOU effect. The deletions change d_0.95 by at most 0.041 for one respondent and 0.056 for two, and d_0.90 by at most 0.028 and 0.042. The screen and the tolerance path agree that the strict boundaries rest on one or two respondents, and the path reports the dependence while keeping respondents whose answers may be valid.

12.4 The dependence-matched reference band

The reference band compares each observed effect size with 999 datasets from a Gaussian copula that keeps the empirical marginals and the normal-score rank correlation of the pair and imposes no attainability floor. The band is a proposed diagnostic with operating characteristics still to be established.

band <- do.call(rbind, lapply(seq_along(pairs), function(idx) {
  X <- s[[pairs[idx]]]; Y <- s$USE
  b <- spuriousness_band(X, Y, pi_grid = pi_grid, n_grid = 400L, M = 999L,
                         scope = c(min(X), max(X), min(Y), max(Y)), seed = 20261030L + idx)
  cbind(pair = pairs[idx], rank_correlation = b$rank_correlation, b$band)
}))
print(band, digits = 3, row.names = FALSE)

12.6 What QNCA adds to the published analysis

A report needs both diagnostics beside the ordinary permutation result. The tolerance path shows that each strict boundary rests on a thin set of efficient respondents and that the published effect sizes move strongly with the exception tolerance. The band shows that every member of the grid stays within what the observed marginals and rank dependence reproduce in the absence of an attainability floor. The evidence leaves AD, EMV, EOU, PU and CO without support as necessary bottlenecks for USE beyond the reproduced dependence and skewness, and the strict bottlenecks that an applied report would quote are the bottlenecks most exposed to a single efficient respondent. A managerial threshold therefore rests on the permutation result, the tolerance path and the band together (Deja 2026b).

The latent scores come from the partial least squares model estimated with seminr in R, so every number of the reanalysis is computed in R.
